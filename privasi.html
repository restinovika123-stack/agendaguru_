AgendaGuru

Kebijakan Privasi

Berlaku sejak 27 Oktober 2026

Ringkasnya: data kelas, siswa, nilai, dan absensi Anda disimpan di Google Spreadsheet milik Anda sendiri. Pengembang AgendaGuru tidak menerima, menyimpan, atau menjual data tersebut.

1. Data yang dikelola aplikasi

  • Akun guru: nama, email, dan password (password disimpan dalam bentuk acak/hash, bukan teks asli).
  • Data sekolah dan kelas: nama sekolah, alamat, wali kelas, kepala sekolah, mata pelajaran, jadwal, jurnal.
  • Data siswa: nama, NIS/NISN, tempat/tanggal lahir, jenis kelamin, agama, alamat, nama dan nomor HP orang tua/wali.
  • Data pembelajaran: absensi, nilai, kokurikuler, ekstrakurikuler, poin, catatan wali kelas, foto bukti jurnal (jika diunggah).

2. Di mana data disimpan

  • Google Spreadsheet milik guru, dijalankan oleh Google Apps Script di akun Google guru tersebut. Ini tempat penyimpanan utama.
  • Google Drive milik guru, folder AgendaGuru_Bukti, untuk foto bukti jurnal. Folder ini bersifat privat.
  • Perangkat guru (penyimpanan browser), sebagai salinan sementara agar aplikasi tetap bisa dibuka saat offline. Salinan ini dihapus saat guru menekan Keluar Akun.

3. Yang tidak dilakukan pengembang

  • Tidak menyimpan data guru atau siswa di server pengembang.
  • Tidak membaca, menjual, atau membagikan data kepada pihak lain.
  • Tidak memasang iklan atau pelacak (tracking) di dalam aplikasi.

4. Layanan pihak ketiga

  • Google (Spreadsheet, Apps Script, Drive, Calendar): mengikuti kebijakan privasi Google.
  • GitHub Pages: menyajikan tampilan aplikasi. Data guru tidak dikirim ke GitHub.
  • Penyedia pustaka tampilan (jsDelivr, cdnjs, Google Fonts) dan ui-avatars.com (gambar inisial profil, menerima nama guru untuk membuat gambar inisial).
  • WhatsApp: hanya dibuka saat guru menekan tombol kirim pesan ke orang tua.

5. Keamanan

  • Akses data membutuhkan login. Password disimpan sebagai hash di akun Google guru.
  • Login dikunci sementara setelah beberapa kali percobaan gagal.
  • Guru bertanggung jawab menjaga kerahasiaan password dan alamat Aplikasi Web miliknya.

6. Hak guru atas data

  • Melihat dan mengunduh seluruh data langsung dari Spreadsheet miliknya.
  • Mengubah atau menghapus data kapan saja melalui aplikasi atau Spreadsheet.
  • Menghapus semua data dengan menghapus Spreadsheet tersebut dari Google Drive.

7. Data anak

Aplikasi menyimpan data siswa di bawah umur. Guru dan sekolah memastikan penggunaan data sesuai peraturan yang berlaku, termasuk Undang-Undang Pelindungan Data Pribadi (UU No. 27 Tahun 2022), dan hanya memakainya untuk keperluan pembelajaran.

8. Perubahan kebijakan

Kebijakan ini dapat diperbarui seiring perkembangan aplikasi. Tanggal berlaku di bagian atas halaman akan disesuaikan.
